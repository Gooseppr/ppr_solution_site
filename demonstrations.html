Technical showcase

Voir concrètement comment un traitement XML peut être réalisé

Les démonstrations présentées utilisent des jeux de données fictifs créés pour illustrer les traitements et livrables proposés par PPR-Solution. Elles ne correspondent pas à des missions clients.

Chaque cas suit la même logique : problème, données d’entrée, pipeline, résultats et aperçu des livrables.

01

Démonstration · données fictives

Transformation XML A → XML B

Un modèle source doit être transformé vers un modèle cible sans perte silencieuse.

Situation

Un fichier `parts.xml` doit alimenter un modèle `items.xml` attendu par une chaîne documentaire cible.

Données d’entrée

<part id="P-482">
  <label>Hydraulic pump</label>
  <state>legacy</state>
</part>

Pipeline

SOURCE.XML + SOURCE.XSDMAPPINGTRANSFORMATIONTARGET.XML + TARGET.XSDVALIDATION

Mapping

part/@id→item/code
part/label→item/name
part/state→item/status

Livrables

  • source.xmlXML
  • target.xmlXML
  • mapping.csvCSV
  • rapport-transformation.pdfPDF
