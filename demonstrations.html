A. Audit XML multi-erreurs

Maquette à publier

Un corpus fictif accompagné de son XSD : bien-formé cassé, XSD non respecté, namespaces incorrects, références manquantes. La démonstration montrera la classification des erreurs (warning/error) et le rapport de synthèse produit, le même type de résultat que la prestation Contrôle et qualification XML.

Démonstration technique : corpus fictif créé spécifiquement pour PPR-Solution. Pas encore publiée dans le dépôt.

B. Extraction XML vers Excel

Maquette visible

Un corpus fictif de plusieurs centaines de fichiers XML : extraction XPath de plusieurs informations par fichier, consolidation dans un tableau Excel unique avec statistiques. Cette démonstration illustre que PPR-Solution ne fait pas que valider du XML : elle en exploite le contenu. Correspond à la prestation Extraction et exploitation de données XML.

Démonstration technique : corpus fictif. Pas encore publiée dans le dépôt.

C. Transformation XML A vers XML B

Mapping à publier

Un XSD source, un XSD cible, le mapping entre les deux modèles, la transformation appliquée et la validation du résultat contre le schéma cible. Correspond à la prestation Transformation et conversion XML.

Démonstration technique : cas fictif. Pas encore publiée dans le dépôt.

D. XML vers PDF / HTML

Aperçu disponible

Un XML source, la transformation XSLT/XSL-FO appliquée, un aperçu PDF et éventuellement HTML, accompagnés d'un rapport de génération. Un premier aperçu de ce type de transformation est déjà visible sur la page Génération documentaire à partir de XML.

Démonstration technique : cas fictif. Rapport de génération détaillé pas encore publié dans le dépôt.

E. Comparaison XML

À cadrer

Une version de référence (baseline) et une nouvelle version d'un même corpus : différences structurelles et de valeurs, ajouts, suppressions, éléments nécessitant une décision humaine. Correspond à la prestation Analyse et comparaison XML.

Démonstration technique : cas fictif. Pas encore publiée dans le dépôt.

F. Précontrôle d'un corpus S1000D

Disponible

Notre validateur XML S1000D est un outil de démonstration fonctionnel, dès aujourd'hui : chargez un module S1000D (Issue 6.0) et obtenez un contrôle structurel en temps réel.

Un jeu d'essai basé sur un corpus public d'exercice (par exemple le Bike Sample S1000D) est en préparation pour illustrer le précontrôle sans dépendre d'un fichier client. Ce corpus, lorsqu'il sera intégré, restera en lecture seule et sera présenté comme un corpus d'exercice, jamais comme un client, et sans qu'aucune certification de conformité ne soit délivrée.
