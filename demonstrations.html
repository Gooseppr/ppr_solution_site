Démonstrations

Cette page rassemble nos démonstrations techniques et jeux d'essai. Elle deviendra progressivement notre portfolio technique. Aucun élément présenté ici n'est un projet client réel : il s'agit uniquement de démonstrations, de cas fictifs ou de corpus publics utilisés à des fins pédagogiques.

A. Audit d'un XML rejeté

En préparation

Un fichier XML valide, une copie volontairement rendue incorrecte, un schéma XSD associé et le rapport d'anomalies correspondant. L'objectif : montrer comment une anomalie est détectée, classée et expliquée.

Démonstration technique — jeu d'essai créé spécifiquement pour PPR-Solution. Le contenu de cette démonstration n'est pas encore publié dans le dépôt.

B. XML vers PDF / HTML

En préparation

Un XML source, la transformation appliquée, un aperçu PDF et éventuellement HTML, accompagnés d'un rapport de génération. Un aperçu de ce type de transformation est déjà visible sur notre page Transformation et publication documentaire.

Démonstration technique — cas fictif. Le rapport de génération détaillé n'est pas encore publié dans le dépôt.

C. Précontrôle d'un corpus S1000D

Disponible

Notre validateur XML S1000D est un outil de démonstration fonctionnel : chargez un module S1000D (Issue 6.0) et obtenez un contrôle structurel en temps réel.

Un jeu d'essai basé sur un corpus public d'exercice (par exemple le Bike Sample S1000D) est en préparation pour illustrer le précontrôle sans dépendre d'un fichier client. Ce corpus, lorsqu'il sera intégré, restera en lecture seule et sera présenté comme un corpus d'exercice — jamais comme un client, et sans qu'aucune certification de conformité ne soit délivrée.

Tester le validateur XML S1000D

D. Comparaison / non-régression

En préparation

Une version de référence (baseline), une nouvelle version, les différences structurelles et documentaires identifiées, puis une synthèse permettant une décision éclairée.

Démonstration technique — cas fictif. Non encore publiée dans le dépôt.
