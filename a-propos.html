Personal / minimal

Une activité indépendante dédiée au XML

PPR-Solution n’est pas une agence. C’est une activité indépendante structurée autour d’un atelier technique XML.

Le même interlocuteur suit le cadrage, le traitement, le contrôle et la livraison.

Positionnement

Spécialiste indépendant des traitements XML

Le cœur d’activité couvre la validation XML, XSD, DTD, Schematron, XPath, XQuery, XSLT, l’extraction, la transformation, la migration, la comparaison et la génération documentaire. S1000D est une spécialisation importante dans ce périmètre, pas l’identité entière.

Méthode

Cadrer, tester, traiter, contrôler, livrer

Une intervention commence par un échantillon représentatif, les règles disponibles et les livrables attendus. Le traitement est ensuite testé sur un périmètre réduit avant généralisation.

Atelier XML

Un environnement de production interne

L’atelier XML regroupe des scripts, mappings, contrôles, journaux et procédures utilisés pour produire les livrables. Il n’est pas vendu comme logiciel : le client achète la prestation et ses résultats.

Automatisation + contrôle humain

Un script qui réussit ne suffit pas

Un traitement peut s’exécuter sans erreur tout en produisant un résultat discutable métier. L’automatisation traite le volume ; le contrôle humain qualifie les limites, les rejets et les décisions à prendre.

Confidentialité

Échantillon anonymisé et transfert adapté

Le validateur public n’est pas le canal prévu pour des fichiers confidentiels. Pour une mission réelle, les modalités de transfert sont convenues selon le niveau de sensibilité : échantillon anonymisé, NDA si nécessaire, canal dédié si pertinent.
