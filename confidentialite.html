Politique de confidentialité

Cette politique décrit les traitements visibles dans le site et les services techniques auxquels il fait appel.

Dernière mise à jour : 4 septembre 2026

Responsable et contact

Les traitements décrits sur cette page sont mis en œuvre pour PPR-Solution. Pour toute question ou demande relative à vos données, utilisez le formulaire de contact.

Formulaire de contact

L’adresse email et le message sont obligatoires. Le nom, l’entreprise, le type de besoin, les formats, les schémas, l’échéance et le choix de recevoir des informations occasionnelles sont facultatifs.

Ces informations servent à qualifier la demande et à y répondre. Si la case correspondante est cochée, elles peuvent aussi servir à envoyer des informations occasionnelles sur les services.

Le formulaire transmet les données à PPR-Solution par un service Google Apps Script. Le code serveur et ses réglages de conservation ne figurent pas dans ce dépôt public. Consultez la politique de confidentialité de Google pour les traitements propres à ce prestataire.

Validateur S1000D

Le fichier XML sélectionné est envoyé à l’API s1000d-api.vercel.app/validate afin de produire le résultat de validation affiché dans le navigateur. La limite appliquée par le site est de 10 Mo.

Le contenu d’un fichier XML peut inclure des informations confidentielles ou des données à caractère personnel. Ne transmettez pas de document sensible sans garanties préalables adaptées. Le dépôt du site ne permet pas de vérifier la localisation du traitement, la journalisation, ni la durée de conservation appliquée par l’API.

Hébergement et ressources externes

Le site statique est publié avec GitHub Pages. GitHub indique enregistrer et conserver l’adresse IP des visiteurs de sites GitHub Pages à des fins de sécurité. Consultez la documentation GitHub Pages et la déclaration de confidentialité de GitHub.

Les polices sont chargées depuis fonts.googleapis.com et fonts.gstatic.com. Le navigateur adresse donc des requêtes à Google lors du chargement des pages.

Cookies et mesure d’audience

Le code actuel du site ne dépose pas de cookie et n’utilise ni stockage local ni stockage de session. Aucun outil de mesure d’audience actif n’a été identifié dans les pages publiées.

Durées de conservation

Aucune durée précise et vérifiable n’est définie dans le dépôt pour les données du formulaire, les journaux techniques des prestataires ou les fichiers transmis au validateur. Ces durées doivent être définies et confirmées par le responsable du site et les prestataires concernés.

Vos droits

Selon la réglementation applicable à votre situation, vous pouvez demander l’accès, la rectification ou l’effacement de vos données, vous opposer à certains traitements ou retirer votre accord aux informations occasionnelles. Ces demandes peuvent être adressées via le formulaire de contact.
